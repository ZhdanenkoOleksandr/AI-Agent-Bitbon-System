# ⬡ KB Admin — Платформа управления базой знаний

Веб-платформа для создания базы знаний с AI-анализом и ручной проверкой администратора.

**Принцип:** Загружаешь PDF или текст → Claude анализирует каждый фрагмент → ты лично читаешь, редактируешь и одобряешь → только проверенные знания попадают в базу.

![Platform Screenshot](https://via.placeholder.com/800x400/0d1117/f0a73a?text=KB+Admin+Platform)

---

## Возможности

- 📄 **Загрузка PDF** — перетащи или кликни, текст извлекается автоматически
- ✂️ **Умная нарезка** — текст режется на смысловые блоки с перекрытием
- 🤖 **AI-анализ** — Claude определяет сегмент, пишет резюме, вытаскивает концепты, оценивает качество
- 👁️ **Ручная проверка** — читаешь каждый блок, редактируешь текст и сегмент, добавляешь заметки
- ✓/✗ **Одобрение/отклонение** — только проверенные знания попадают в базу
- 💾 **Экспорт JSON** — вся одобренная база скачивается одним файлом

## Настройка под свой проект

### Изменить сегменты базы знаний
Открой `js/config.js` и отредактируй массив `SEGMENTS` и цвета `SEG_COLORS`:

```js
SEGMENTS: [
  'my_segment_1',
  'my_segment_2',
  // ...
],
SEG_COLORS: {
  my_segment_1: '#58a6ff',
  my_segment_2: '#f0a73a',
},
```

### Изменить модель Claude
```js
MODEL: 'claude-opus-4-6',  // по умолчанию claude-sonnet-4-20250514
```

### Изменить размер чанков
```js
CHUNK_WORDS:   180,   // слов в одном чанке (150-300 — оптимально)
OVERLAP_WORDS:  30,   // слов перекрытия между соседними чанками
```

### Изменить промпт анализа
Отредактируй метод `buildAnalysisPrompt()` в `js/config.js` — добавь дополнительные поля или измени критерии качества.

```
       ↓

```

## Использование базы в RAG-агенте

После экспорта JSON подключаешь к своему агенту:

```python
import json

with open('kb_2025-05-01.json') as f:
    kb = json.load(f)

# Простой поиск по ключевым словам
def search(query, segment=None):
    chunks = kb['chunks']
    if segment:
        chunks = [c for c in chunks if c['analysis']['segment'] == segment]
    query_lower = query.lower()
    return [
        c for c in chunks
        if any(w in c['text'].lower() for w in query_lower.split())
    ]

# Или загружай в ChromaDB для векторного поиска
# (см. knowledge_pipeline в отдельном репозитории)
```
